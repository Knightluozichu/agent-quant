# A股结构交易实战原理

## Overview

独股一箭的隔日超短和缠中说禅的中枢背驰是两套互斥的分类系统。贯通点只有一条：先写下这笔交易的命题，退出只由命题被破坏决定。固定百分比、ATR 倍数、目标价和持仓天数是第三套语言，写进退出条件，这笔交易就不再属于这两套。

来源边界：独股规则只取天涯实盘帖《超短线之决战 2010》及其同期交割单所呈现的行为，不取后来的二板定龙、集合竞价打板。缠论只取《教你炒股票 108 课》的走势分类，不取后学指标化口诀。一次历史盈利不是有效性证据。本技能用于研究、复盘和规则审查，不连接真实资金，不承诺收益。

几何定义见同目录 `reference.md`。下面是下单前必须走完的程序。

## 先选模式

```
这笔仓要表达什么？
├─ 只参与热点里最强的那一下，次日按预期了结 → 隔日模式
├─ 持有到某个操作级别的走势走完 → 缠论模式
└─ 两种理由都想要 → 停止。拆成两笔，或空仓
```

同一笔仓位只有一个模式、一个命题、一个失败定义。不允许用中枢解释隔日仓为什么可以多留一天，也不允许用“明天必须走”打断一个尚未出现卖点的操作级别持仓。

## 决策卡

给出任何买卖建议之前，先填这张卡。有空栏，或退出栏写成百分比、ATR、目标价、持仓天数，卡作废，重写。

| 栏 | 要写什么 |
|---|---|
| 模式 | `隔日` 或 `缠论` |
| 命题 | 一句话：市场已经呈现了什么，所以才买 |
| 边界 | 隔日：次日了结。缠论：操作级别（如 30 分钟走势），不是 K 线周期的别名 |
| 买点类 | 隔日四类或缠论四类之一，见下 |
| 失败 | 哪个已观察事实出现，命题即死。写价格结构或次日盘面事实 |
| 走完 | 哪个已观察事实出现，命题完成，离场 |
| 环境 | 通过了哪条环境过滤 |
| 资金 | 研究假设。未单独授权时不改 `configs/risk.yaml`，不触达券商 |

## 隔日模式

时钟是 A 股 T+1 下的隔日：今天进，明天结。小资金的结构是单票进出，卖完立刻可以换下一只；分仓会把隔日切换做成持仓组合。这是研究假设。本仓库生产风控仍是多标的、单票上限和现金缓冲，未单独授权不得把“满仓一只”写成生产仓位。

选股是赢的充分条件，纪律和手法只是必要条件。每天先有热点判断，再在该热点里收集强势股（量级约 10 只），只在盘面给出时机时狙击。

强势股同时具备：当下热点、股性活跃、涨停坚决或不断创新高、量能持续且均匀。龙头是这个热点里涨得最多、最猛、能带动板块的那一只。环境差时跟风直接剔除。极强的票在大盘不好时仍不轻易破 10 日线，且破位时不放量。

热点是否能延续，看量能是否持续均匀。一日游和持续走强的差别在这里，不在消息多少。

### 买点四类

只在下面四类里选一类写入决策卡。

1. **突破跟随**。日线或分时突破平台、前高或历史新高之后，回调到分时均价附近，承接还在，第一时间跟。追涨看的是突破本身，以及当日是否领着大盘、是不是前期强势股。其次才是量能。
2. **强势回踩**。一波上涨之后缩量回到 5 日或 10 日一带，盘中冲高再回到分时均价才买。题材、热点、上涨形态三者齐。高位票盘中不追高。
3. **二次放量**。已经有过一波涨幅的核心标的，开盘成交量严格大于上一交易日开盘成交量。这是盘整转上涨能看到的第一下。
4. **飞刀**。只用于最新强势股的第一波破位，且早盘已经把恐慌盘杀出来，只博该股自己的重要均线。均线死叉或空头排列时成功率低，默认不做。命题里要写明“杀够了”的盘面事实；写不出，这一类关闭。

早盘进靠选股和预判，空间大，博的成分大。午盘进靠已经走出的盘面，较稳，容易追高，空间小。两条不能混成“盘中看着办”。

90% 的股票要看大盘。真正的热点在大盘刚开始变差时可以忽略大盘，那段回落是低买窗口；大盘若是暴跌，窗口关闭。大盘连续杀跌超出预期时，不做高位强势股，等大幅补跌之后再看。熊市里突破多为假突破，突破跟随降级或关闭，只留强势回踩和飞刀里已写明的那一类。

2010 年帖里的 8 元、10–30 元是当时价格体系。今天只保留性质过滤：排除 ST、停牌、超大盘、绝对高价、绝对低价。不把当年的价格数字当阈值。

### 退出

买入当天就把预期写死，预期来自当天强弱，不在次日盘中改。

- 次日是这套的持仓边界。除非开盘后快速大单封死涨停，否则见好就收。不在涨停价上计较最后一截。
- 当天已经证明买错：假突破、冲高无量、利好出来却不封板。次日开盘走。
- 次日弱于写死的预期：高开低走、冲高无量、跌破分时均线后的反抽无力。走。
- 卖飞的股票只在下一次独立买点重做，不因为卖飞把隔日改成持有。

亏损几个点是结果，不是触发器。触发器是“预期没有出现”。

只攻不守的含义是：防守已经做在买点里（只做最强、不追高、买在承接处），账户不靠扛单防守。猛和狠（单票、每日进出）只有在稳和准同时成立时才允许。主观判断压过盘面，命题作废。

## 缠论模式

先选定操作级别，并且只按这个级别的买卖点行动。30 分钟走势类型不等于“30 分钟 K 线”；级别由次级别走势重叠自组出来，K 线周期只是观察它的显微镜。

几何按 `reference.md` 当下完成：包含关系 → 分型 → 笔 → 线段 → 中枢 → 走势类型。未完成的笔、线段、中枢不能提前当成完成。走势终完美的操作含义是：该级别走势类型在走完之前会延续；走完之后才转化成另一类。不预测它怎么走完。

盘整：该级别一个完成走势里只有一个中枢。趋势：至少两个依次同向、区间不重叠的中枢。后一个中枢的下沿高于前一个中枢的上沿，是上涨；反过来是下跌。两个中枢的波动区间重叠，是更大级别中枢，不是趋势延续。

### 买点四类

1. **一买**。下跌趋势的背驰点。比较对象是：离开最后一个中枢的那段，对连接前两个同向中枢的那段。后段力度小于前段，才是趋势背驰。只有一个中枢的底背是盘整背驰，力度可疑，不按一买处理。
2. **二买**。一买之后，次级别上涨结束，回调不破一买低点。它由次级别的一买构成。
3. **三买**。中枢已经形成。一个次级别走势向上离开，其后的次级别回抽低点不跌破中枢上沿 ZG。离开和回抽的组合只允许：趋势+盘整、趋势+反趋势、盘整+反趋势。盘整+盘整不是破坏。优先做第一个中枢的三买；第二个中枢之后，长成大级别中枢的概率急增。
4. **中枢震荡**。本级别中枢内部没有本级别的三类买卖点。次级别向下离开出现底背驰可以介入；回拉的顶背驰高点不能越过前一次向上离开的高点，就走。回拉不重新回到中枢，是三卖，必须走。回抽不重新回到中枢，是三买，接回。

卖点与买点对称。任一背驰制造某级别买卖点；任一级别买卖点都来自某级别背驰。大级别转折用区间套：先圈定大级别背驰段，再在次级别里找该段内部的背驰段，收到能反应的最低级别。不是大级别里面任意一个小买卖点。

力度比较用这段走势自身的内部结构。MACD 柱面积只是辅助：黄白线刚离开 0 轴时没有背驰可比较；要先有一次离开、回抽 0 轴、再离开，才比较后一次与前一次。

趋势背驰之后，最后一个中枢面对三种完成方式：级别扩展、更大级别盘整、该级别以上的反趋势。三种都算背驰成立后的转折，不默认价格立刻反向。

### 退出

退出只有卖点和买点结构死亡。

- 一买死亡：价格创新低，且新低这一段的力度不小于被它打破的那一段。
- 二买死亡：价格跌破一买低点。
- 三买死亡：回抽低点跌破 ZG，重新进入原中枢。
- 持仓走完：操作级别出现一卖或二卖；震荡仓出现上面写的顶背驰或三卖；三买之后的次级别向上不创新高，或出现盘整背驰。
- 三买若进入新的中枢上移，持有到这次上移出现背驰，至少减掉一半；下一次次级别上去若不创新高或出现盘整背驰，清完。

操作级别的结构还在时，小级别卖点只做短差：次级别一卖减仓，次级别一买回补，不把大级别仓清掉。抄一个级别的底，后面最坏还有同级别盘整；这段盘整自己的三段次级别没走完之前，不因为第一次冲高回落离场。

下跌趋势里，第一个中枢的三卖是顺势最后一处合适卖点。第二个中枢之后看的是有没有背驰买点。趋势背驰后的第一段向上，常常正好打在最后一个中枢的三卖上，那个三卖没有操作意义，要等的是下来的二买。

A 股 T+1：当天新建的仓不能在当天按分钟级别卖点来回。没有底仓时，操作级别不得细到必须当日反向的级别。已有底仓的短差才可以使用次级别买卖点。

## 环境、仓位、账本

两套系统各自的环境过滤写在决策卡里，不共用一个“大盘均线多头才能开仓”。

隔日仓的风险预算是时间：错了次日走，所以单笔可以重，但重仓只存在于注明了的研究假设里。缠论仓的风险预算是结构宽度：失败点离买点的价格距离决定仓位，距离大到超出研究预算就放弃这笔，不把失败点改近。

本仓库已有的趋势持有、回调波段、区间回归、熊市反弹，使用结构或 ATR、分层目标、时间止损和持仓天数。审查那些策略时用它们自己的配置。审查对象一旦声明为隔日或缠论，退出栏改回命题失败，不把 `stop_loss_pct`、`take_profit`、`max_holding_days` 映射过来。

`ALLOW_LIVE_TRADING` 默认关闭。本技能不生成实盘订单。

## 红旗

出现任一条，停下来重填决策卡。

- 退出写成亏 3%、亏 5%、赚 10%、2 倍 ATR、拿满 N 天
- 一笔仓同时写了“次日走”和“持有到三买”
- 用涨停或热点给一个没有背驰的位置起名为一买
- 用中枢给一个隔日仓增加第二天以后的持有理由
- 中枢还没被离开和回抽确认，就把突破当成三买
- 盘整背驰按趋势反转持有
- 背驰段还没用区间套收到可反应级别就下单
- 飞刀没有写明恐慌盘已经杀出
- 高位盘中追价，仍称这是隔日模式
- 把 2010 年单月交割结果写成方法有效
- 把研究满仓写成生产订单

## 常见借口

| 借口 | 处理 |
|---|---|
| 结构止损太远，先按 5% 保护 | 距离超出预算就放弃这笔。不把失败点改成百分比 |
| 隔日和缠论看的是同一只强势股，可以叠加 | 理由不同就拆成两笔。叠在同一仓位上，失败定义会互相取消 |
| 次日封不住但没跌破成本，再看一天 | 隔日的边界是预期，不是成本。预期没出现就走 |
| MACD 顶背离就是缠论背驰 | 先有两个同向不重叠中枢，再比较离开段与连接段。柱子缩短只是辅助 |
| 三买就是突破中枢上沿 | 要等离开的次级别走完，并且回抽低点仍在 ZG 之上 |
| 小级别卖点出现，大级别一并清掉 | 大级别结构未被破坏，小级别只做短差 |
| 这只是研究参数，百分比不影响原理 | 退出栏一旦是百分比，研究的就不是这两套 |

## 示例

隔日，合格：

- 命题：某热点最强票当日放量突破平台，分时回落到均价仍有承接。
- 买点类：突破跟随。
- 失败：次日开盘后冲高无量，或低开后不能回到分时均价。
- 走完：次日冲高兑现；若开盘快速大单封死涨停，持有到封单失败。
- 不写目标涨幅。

缠论，合格：

- 命题：日线下跌趋势已有两个不重叠中枢，离开后一中枢的段力度小于连接段，且 30 分钟区间套背驰成立。
- 买点类：一买。
- 失败：30 分钟再创新低，且该段力度不小于这一买所比较的前段。
- 走完：日线一卖；或次级别上涨后的回调跌破一买，则二买不成立，原仓结束。
- 不写“跌 8% 止损、涨 20% 止盈”。

## 实操顺序

1. 声明模式。声明不了就空仓。
2. 填决策卡。退出栏出现百分比就重写。
3. 隔日：先热点，再强势股池，再四类买点之一，盘中不改类别。
4. 缠论：先操作级别，再按 `reference.md` 画到当下，只在四类买点出现时进。
5. 盘后把“失败是否出现、走完是否出现”记成事实，不记成盈亏百分比。
6. 要改规则，改的是分类定义。不把一笔盈亏写回生产参数。
