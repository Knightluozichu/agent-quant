# 结构定义

操作时以 `SKILL.md` 的决策卡为准。这里只放分类所需的定义，避免和退出程序缠在一起。

## 隔日：盘面事实

这些事实用来填写决策卡的失败栏和走完栏，都是当时看得到的。

| 事实 | 含义 |
|---|---|
| 承接还在 | 突破或冲高之后，回落到分时均价附近不再继续放量下杀 |
| 冲高无量 | 次日价格冲高，但量能达不到买入当天为它写下的预期 |
| 涨停坚决 | 封板干净；利好日出动后不能封板，按走处理 |
| 持续均匀量能 | 热点多日维持量能，而不是单日脉冲 |
| 领涨 | 当日开盘后强于大盘，并且是该热点里最强的一只 |
| 假突破 | 突破当天冲高后回到平台内，收盘已经否定突破 |

强势股池每天重建。池子里的票只是候选，没有买点类就不动。

## 缠论：从 K 线到走势类型

### 包含关系

相邻两根 K 线，一根的高低点完全落在另一根范围内，先合并再谈分型。

- 方向向上：高点取两根中较高者，低点取两根中较高者。
- 方向向下：低点取两根中较低者，高点取两根中较低者。
- 方向由前一根非包含 K 线决定。第 n 根与第 n+1 根包含，且第 n 根不包含第 n-1 根时：第 n 根高点不低于第 n-1 根高点，为向上；第 n 根低点不高于第 n-1 根低点，为向下。
- 按顺序合并。第 1、2 根包含，第 2、3 根包含，不推出第 1、3 根包含。

### 分型

在没有包含关系的 K 线上，相邻三根：

- 顶分型：中间 K 线的高点最高，且其低点也最高。
- 底分型：中间 K 线的低点最低，且其高点也最低。

相邻分型不共用 K 线。所有顶点都是顶分型，所有底点都是底分型。没有顶分型就没有顶。分型可以是中继：它延不延成笔，看该分型对应的小级别中枢有没有走出第三类买卖点。分型本身不是买卖点。

顶分型的力度辅助：非包含处理后，第三根跌破第一根低点，且不能收在第一根区间一半之上，杀伤力大。第二根长上影或长阴，第三根不能收到第二根区间一半之上，延成笔的可能大。第一根长阳、后两根小阴小阳，多为中继。这是力度分类，不是止损线。

### 笔

一笔连接相邻的顶分型和底分型。

- 顶和底之间至少有一根 K 线不属于这两个分型。
- 顶分型里最高那根 K 线的区间，至少有一部分高于底分型里最低那根 K 线的区间。
- 新笔的附加条件：在不共用 K 线的前提下，顶分型最高 K 与底分型最低 K 之间（不含这两根），不重复计算包含，至少还有 3 根 K 线。

划分：先取全部分型；同类分型里，后面的顶更高则丢掉前面的顶，后面的底更低则丢掉前面的底；剩下相邻的顶和底连成笔。笔的划分唯一。笔没完成时，不能把更低的底直接连进同一向下笔。

### 缺口

单位 K 线上，相邻两根之间没有成交的价格区间是缺口。

- 顺向且包含在一笔里的缺口，不单独破坏笔。
- 逆向的突然缺口，按一段处理：看成三段缺口叠加，从而满足“至少三笔”。
- 不回补：强。回补后继续新高或新低：平。回补后不能新高或新低：弱，原趋势转折，调整级别大于缺口所延续的那次趋势。
- 盘整里的普通缺口，中枢震荡的回拉几乎会补到缺口位置。这是震荡目标，不是反转信号。

### 线段

线段至少三笔，笔数为单数，前三笔必须有重叠。向上线段由向上笔开始，向下线段由向下笔开始。

特征序列：向上线段看其中向下笔的序列，向下线段看其中向上笔的序列。特征序列先做包含处理，得到标准特征序列。向上线段的结束只考察特征序列的顶分型，向下线段只考察底分型。

- 第一种结束：构成分型的第一与第二元素之间没有缺口。线段在该分型的高点或低点结束。
- 第二种结束：第一与第二元素之间有缺口。从该极值起的反向笔序列，其自身特征序列出现分型，原线段才在该极值结束。这里的第二个分型不再区分有没有缺口。

线段只能被反向线段破坏。第一种笔破坏若延伸不出重叠的三笔，原线段没结束。破坏可以逆时间传递：后线段破坏了中间线段，则中间线段之前的那条也已结束。分析用的线段可以标准化成“向上线段低点起、高点终；向下线段高点起、低点终”。

### 中枢

某级别中枢是至少三个连续次级别走势类型的价格重叠。记三段的高点为 a1、b1、c1，低点为 a2、b2、c2：

- ZG = min(a1, b1, c1)
- ZD = max(a2, b2, c2)
- 必须 ZD < ZG，否则没有重叠，没有中枢

中枢由与中枢方向一致的次级别段（Z 走势段）的重叠确定。回升形成的中枢看向上段，回调形成的中枢看向下段。

把中枢内所有 Z 段的高点、低点记为 gn、dn：

- GG = max(gn)，G = min(gn)，D = max(dn)，DD = min(dn)
- 前三段给出的 [ZD, ZG] 是中枢区间

延伸：任意后续段 [dn, gn] 仍与 [ZD, ZG] 重叠。某一段 dn > ZG，或 gn < ZD，则产生更大级别中枢，或趋势及其延续。

两个同级别中枢：

- 后 DD > 前 GG：上涨及其延续
- 后 GG < 前 DD：下跌及其延续
- 后 ZG < 前 ZD 但后 GG ≥ 前 DD，或后 ZD > 前 ZG 但后 DD ≤ 前 GG：更大级别中枢

中枢越简单，单边力量越强。同一趋势里相邻中枢的形态通常不相同。

### 走势类型

- 盘整：一个完成的走势类型只包含一个该级别中枢。
- 趋势：一个完成的走势类型包含至少两个依次同向的该级别中枢。向上为上涨，向下为下跌。
- 任何完成的走势类型至少由三段以上次级别走势类型构成。
- 任何级别的任何走势，都可以分解成同级别盘整、下跌、上涨的连接。

趋势里，连接两个同级别中枢的，是次级别以下的走势类型。盘整里，离开和返回中枢的，也是次级别以下。

更大级别中枢产生，当且仅当围绕连续两个同级别中枢的波动区间发生重叠。在此之前，原级别走势类型延续。

### 中枢破坏与三类买卖点

某级别中枢被破坏，当且仅当：一个次级别走势离开该中枢后，其后的次级别回抽不重新回到该中枢内。

两个次级别的组合只有三种：趋势+盘整、趋势+反趋势、盘整+反趋势。趋势分向上离开和向下离开。实用上最有力的是趋势+盘整。盘整+盘整不是破坏。

- 三买：次级别向上离开，其后次级别回抽的低点不跌破 ZG。
- 三卖：次级别向下离开，其后次级别回抽的高点不升破 ZD。
- 一买：下跌趋势背驰点。一卖：上涨趋势背驰点。
- 二买：一买之后次级别上涨结束，回调不破一买。二卖对称。任何级别的二类买卖点，都由次级别相应走势的一类买卖点构成。

市场里必然产生盈利的买卖点只有这三类。任何向上或向下都从三类买卖点之一开始，也在三类买卖点之一结束。

中枢内部没有本级别三类买卖点。第三类买卖点出现，原中枢死亡，走势向新中枢移动。

### 背驰

趋势背驰的结构是 a+A+b+B+c：A、B 是同向的两个中枢，c 是离开 B 的段，b 是连接 A 与 B 的段。c 的力度小于 b，才是趋势背驰。

盘整背驰：离开中枢这一段的力度，小于进入中枢那一段。其后可以只回到中枢。

力度是这段走势的内部结构。MACD 红绿柱面积是辅助，不是定义。黄白线刚上 0 轴，没有完成“离开、回抽、再离开”，不能比较背驰。

背驰-转折：某级别趋势背驰，将导致该趋势最后一个中枢级别扩展、该级别更大级别的盘整，或该级别以上级别的反趋势。

区间套：大级别转折先找到背驰段，再在次级别图上找这段内部的背驰段，逐级收到最低可操作级别。理论上可以收到笔的背驰。

小转大：小级别顶背驰引发大级别向下，必要条件是该级别最后一个次级别中枢出现三卖。底背驰引发大级别向上，必要条件是最后一个次级别中枢出现三买。这是必要，不是充分。

买卖点级别：大级别买卖点必然是次级别以下某一级别的买卖点。不同级别可以同时出现一类买卖点。

### 缺口、分型与 5 周期均线

108 课里，日线顶分型之后是否有效跌破 5 日线，用来辅助判断这个分型会不会延成向下笔。判断仍以小级别是否盘整背驰为准。这里的 5 日线不是隔日模式的买点，也不是止损价。

### 操作程序（三买）

1. 选定够反应的操作级别。
2. 只在该级别三买介入。
3. 买入后，新的次级别向上不能新高，或出现盘整背驰，卖掉。
4. 若进入该级别中枢上移，持有到上移背驰，至少卖一半；下一次次级别上去不创新高或盘整背驰，清完。
5. 尽量只做第一个中枢的三买。
6. 走了之后是否再做，看高一级别中枢有没有可能形成第三类买卖点。

中枢震荡程序：向下离开只要出现底背驰就可以介入；回拉的顶背驰若不能越过前一次向上离开的高点，一定走；能越过也可以走。次级别回抽一旦不回到中枢，三买出现，买回。从底背驰开始的回拉若不能回到中枢，三卖出现，走，等下面的新中枢。

### 级别生长

最低级别可以用分型、笔、线段当递归起点。其上每一级中枢，都是三个连续次级别走势类型的重叠。1 分钟、5 分钟、30 分钟、日线这些名字是观察用的周期；“三个连续 1 分钟走势类型的重叠构成 5 分钟中枢”是便于操作的说法，严格级别仍按重叠生长，不按时钟换算。

同级别分解里，中枢都是同级别的，盘整中枢不把三段以上的延伸继续算进同一个未完成盘整；三段次级别重叠完成后，这一段同级别走势就划分掉。

## 两套定义不许互换

| 词 | 隔日里指 | 缠论里指 |
|---|---|---|
| 强 | 热点中涨得最猛、量能持续、涨停坚决 | 中枢简单、离开段力度大于前段、缺口不回补 |
| 背离 | 不使用这个词当卖点 | 趋势背驰或盘整背驰，比较对象见上 |
| 支撑 | 5 日、10 日或该股当时的重要均线，且承接还在 | 中枢下沿 ZD、一类买点低点、分型低点 |
| 突破 | 平台或前高之后的回踩跟随 | 不是买点。离开加回抽不回 ZG 才是三买 |
| 止损 | 次日预期没有出现 | 买点结构死亡或操作级别卖点 |
