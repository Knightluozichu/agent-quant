# Project C：月 12–30%、MDD -10%、仅 A 股/ETF（候选 C1/C2 首轮否证）

- 日期：2026-11-02
- 状态：新项目，不基于 V5 调参；研究 only，不接券商、不下单
- 约束：10,000 元、仅 A 股/ETF、不加杠杆、目标月 12–30%、最大回撤 -10%

## 结论先行

**C1、C2 两个非 V5 候选都没有通过目标。** 不是“再调一下参数”的问题：

- C1：CAGR 33.1%，MDD **-24.2%**；月 ≥12% 仅 6/71，≥20% 仅 3/71，≥30% 仅 2/71。
- C2：CAGR 1.9%，MDD **-53.4%**；即使加了 -10% 硬闸门，隔夜跳空/T+1 仍让回撤击穿到 -53.4%。

**-10% 回撤不是加一个“止损线”就能实现的。** 日线策略在 T+1 下，止损只能下一开盘执行；跌停/跳空时可能直接击穿。

## 候选设计

### C1：周频横截面动量 top-2
- 池：8 个当前 ETF/LOF + 5 个扩展（标普500、十年国债、德国、恒生中国企业、能源化工）
- 信号：每 5 个交易日，按 20 日收益排序，选正动量 top-2，等权
- 执行：下一交易日开盘；成本单边 0.15%
- 风控：组合回撤 ≤ -10% 时，下一开盘转到 511880 防御，并重置 peak
- 区间：2020-08-04 → 2026-07-27

### C2：日频 20 日突破 top-1
- 信号：收盘价突破过去 20 日最高价，且 20 日动量为正；选最强 1 个
- 执行：下一开盘；持有直到收盘跌破 10 日均线或持有 10 日
- 风控：同样 -10% 组合回撤硬闸门
- 区间同上

## 为什么 -10% 闸门没生效

C2 是典型案例：

- 日线策略只能在**收盘后**知道回撤，下一开盘才能卖；
- 隔夜跳空/跌停时，开盘价可能远低于止损价；
- T+1 无法当天买入当天卖出；
- 所以“组合回撤 -10% 止损”在日线上只能降低部分风险，不能保证 -10% 上限。

要真正控制 -10%，需要：
- 分钟级/盘中止损（仍无法防跳空）；
- 更低仓位/更低波动资产（收益随之下降）；
- 期权/对冲（当前约束不允许）。

## 判断

1. **C1/C2 不通过，不做参数救援。**
2. 目标“月 12–30% + MDD -10%”在仅 A 股/ETF、无杠杆、日线执行下，结构性不可行。
3. 下一轮如果还要继续 C，只剩两类候选：
   - A 股个股事件驱动/涨停延续（需要个股日线/龙虎榜/分钟数据；且 -10% 仍难）；
   - 盘中 T+0/做 T（需要分钟数据、底仓、执行系统；仍无法防跳空）。
4. 如果 -10% 是硬约束，建议把目标降到月 1–2%；如果月 12–30% 是硬目标，建议把 MDD 放宽到 -30% 到 -50%。
