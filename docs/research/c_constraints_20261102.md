# 约束 C 可行性门禁：月 12–30%、最大回撤 -10%、仅 A 股/ETF

- 日期：2026-11-02
- 状态：可行性分析，未开始参数搜索，未接券商，未下单
- 约束：
  - 起始资金 10,000 元
  - 仅可买 A 股股票 / ETF（不做期权/期货/加密）
  - 不加杠杆
  - 月收益 12%–30%，可复利
  - 最大回撤 -10%

## 结论先行

**这四个条件不能同时成立。** 不是“策略还不够好”，是风险预算和收益目标在数学上冲突：

- 要把最大回撤压在 -10%，V5 这种 66.9% CAGR 的引擎只能用到约 **27.9% 的收益暴露**；
- 对应 CAGR 约 **16.8%**，月化约 **1.3%**；
- 距离月 12%–30% 差 **9–23 倍**。

## 1. 目标有多高

| 月目标 | 年化复利 | -10% MDD 下所需 Calmar | 3% 月波动下所需月 Sharpe |
| ---: | ---: | ---: | ---: |
| 12% | +289.6% | 29.0 | 4.00 |
| 20% | +791.6% | 79.2 | 6.67 |
| 30% | +2,229.8% | 223.0 | 10.00 |

V5 的 Calmar 约 **2.06**。目标要求是 V5 的 **14–108 倍**风险调整收益。

## 2. V5 的真实分布

| 指标 | 数值 |
| --- | ---: |
| CAGR | 66.9% |
| 最大回撤 | **-32.4%** |
| 月数 | 76 |

V5 已经能做出 12%–30% 的月份，但代价是 **-32.4% 的最大回撤**，是你 -10% 上限的 3.2 倍。

## 3. 把 V5 压到 -10% 回撤，还剩多少

把 V5 日收益整体缩放到不同暴露（经验上界，不是可交易策略）：

| ---: | ---: | ---: | ---: |

| 25% | 15.0% | -9.0% | 1.17% |
| **27.9%** | **16.8%** | **-10.0%** | **1.30%** |

| 100% | 66.9% | -32.4% | 4.36% |

**在 -10% 回撤约束下，V5 的月化上限约 1.3%，不是 12%。**

## 4. 为什么“股票一天最多 10%”帮不了你

- A 股是 **T+1**，不是 T+0；当天买入不能当天卖出，“做 T”必须先有底仓；
- 10%（主板）/20%（创业板、科创板）是**涨跌停板**，不是你的收益；
- 一个跌停日就可能击穿 -10% 回撤；跌停/跳空时止损不一定成交；
- 10,000 元账户，单笔最低佣金 5 元，高换手成本会先吃掉收益；
- 想用 10% 日涨幅推月 12–30%，等价于要求频繁抓涨停且不回撤——这是彩票，不是可复利策略。

## 5. 三选一：必须放宽一个约束

| 保留 | 放宽 | 现实目标 |
| --- | --- | --- |
| 最大回撤 -10% | 月收益降到 1–2% | 年化 12–25% |
| 月收益 12–30% | 最大回撤放宽到 -30% 到 -50% | 高波动、可能归零，不承诺 |
| 月收益 12–30% + -10% | 放宽交易范围/杠杆/衍生品 | 仍需极强 edge，且 1 万本金/强平/容量限制；不建议 |

**三者不能同时保留。** 这不是能力问题，是约束不相容。

## 6. 如果坚持 C：只能做“否证实验”，不能做承诺

如果用户坚持“月 12–30% + -10% 回撤”，可以做有限次、预注册的否证研究：

- 最多 3 个候选：短周期横截面动量、波动率突破、事件驱动/LOF 溢价；
- 每个候选先过 -10% 组合回撤硬约束；
- 成本 2x/3x、T+1、涨跌停、1 万最小交易单位；
- 输出月度分布、最长连续、最差月、回撤；
- 252 个交易日真样本外；
- **不达标就 no-go，不扫参数、不换区间、不加杠杆硬凑。**

按当前证据，预期结论是：**在 -10% 回撤下，月 12–30% 不可实现。**
