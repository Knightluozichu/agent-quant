# 600322 案例库：同形态全样本扫描 + C9 组合回测

- 日期：2026-11-02
- 目的：不依赖用户逐笔提供，自己在 A 股样本中找 600322 式“深度回撤后早段反转 + 剪刀差卖”的案例
- 数据：191 只随机当前上市 A 股 + 600322；日线 qfq；当前上市样本有幸存者偏差
- 说明：研究 only，不接券商、不下单

## 1. 先确认“剪刀差”是哪一个

600322 2022-11-09：

- 收盘 2.11；MA5 2.040 > MA10 2.007；收盘低于 MA20 2.163；
- MACD：DIF -0.064 < DEA -0.059（11/09 仍死叉）；
- 12/08：DIF 0.096 < DEA 0.098，**MACD 死叉**；
- 12/09 收盘 2.52。

按 11/09 收盘 2.11 买、12/09 收盘 2.52 卖：

```text
+19.4%
```

如果按 MA5/MA10 死叉，11/24 就卖了 2.39，只有 +12.9%。
**所以用户说的“剪刀差”更可能是 MACD 死叉，不是 MA5/MA10。**

## 2. 全样本同形态事件

筛选条件（接近 600322）：

- 总市值 <100 亿；
- 距 60 日高 -15% 到 -45%；
- 收盘 > MA10，MA5 > MA10（近 3 日金叉）；
- 收盘 ≤ MA20 ×1.01（还没站稳 MA20）；
- 量/20 日均量 0.4–1.2；
- 买入 T 收盘；卖出：MACD/MA 死叉、-7% 止损、最长 30 日。

结果：**4,630 个事件**

**典型形态的胜率只有 34%，中位数是亏的；收益靠右尾。**

## 3. C9 组合回测：只做 600322-like

规则：<30 亿、价格<10、-15% 回撤、收盘>MA10、MA5>MA10、量 0.4–0.8x、MACD 死叉卖、-7% 止损、最长30日、最多4只。

| 指标 | C9 MACD |
| --- | ---: |
| 总收益 | +22.1% |
| CAGR | 3.0% |
| 最大回撤 | **-33.7%** |
| 月 ≥12% | 3 / 81 |
| 月 ≥20% | 1 / 81 |
| 月 ≥30% | 0 / 81 |
| 交易次数 | 243 |
| 交易过的股票 | 58 |

集中度测试：

| 最多持仓 | 总收益 | 最大回撤 | 月≥12% | 月≥20% |
| ---: | ---: | ---: | ---: | ---: |
| 1 只 | +8.7% | **-99.5%** | 10 | 4 |
| 2 只 | -13.3% | -70.1% | 5 | 2 |
| 4 只 | +22.1% | -33.7% | 3 | 1 |

**1 只的月度分布最像“有时 20%”，但回撤 -99.5%，不可复利；4 只回撤小一些，但月收益远离 12–30%。**

## 4. 结论

1. **找到了**：600322 式形态确实存在，且“剪刀差”更可能是 MACD 死叉。
2. **形态有正期望**：价格<10 & 市值<30 亿的子集，平均 +1.37%/笔，胜率 42.6%。
3. **但中位数是亏的**：靠少数右尾（+50% 到 +160%）赚钱；用户记得的 600322 是好案例，不是典型。
4. **组合无法稳定 12–30%/月**：4 只 C9 只有 3/81 个月 ≥12%，回撤 -33.7%；1 只能做出更多高月，但回撤 -99.5%。
5. **用户的手动 edge 很可能在“选哪一只”**：板块/政策、筹码、盘中低点、市场情绪；这些不在当前日线因子中。

## 5. 下一步

- 继续找：给样本加**行业/板块**（2022-11 地产链）、**市场 regime**、**上市天数/流通盘/换手**、**前期箱体长度**，看能否把 42.6% 胜率提高到 55%+。
- 不要再扫 MACD/MA 参数；先找“为什么 600322 是前 10%”的解释变量。
- 如果解释变量仍找不到，说明这是主观选择性 edge，系统化只能做“候选池 + 人工确认”，不能全自动。
