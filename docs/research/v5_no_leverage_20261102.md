# V5 无杠杆迭代研究：分析 → 建模 → 回测（2026-11-02）

## 研究问题

不加杠杆、只做多、总仓位不超过 100% 的前提下，V5 能否通过迭代达到年化 100%？如果不能，是参数/池子问题，还是底层收益引擎不足、需要重构？

## 数据与方法

- 数据：`data/cross_asset` 新浪缓存；8 个当前标的 + 5 个候选扩展标的。
- 区间：扩展池共同可得区间 **2020-08-04 → 2026-07-27**（1572 个交易日）。
- 执行：T 收盘信号 → T+1 开盘成交；成本 1x = 单边 0.15%；不加杠杆；总仓位 ≤100%。
- V5 定义：V4 全池快慢共振 + 熔断退出后重置 peak。
- 扩展标的：513500 标普500、511260 十年国债、513030 德国ETF、510900 恒生中国企业、159981 能源化工。
- 对照：服务器腾讯数据全历史 V5 1x（2020-06-19 → 2026-10-30）作为生产参考。

### 1.2 无杠杆“完美年度轮动”上限

假设每年 1 月 1 日拥有上帝视角，直接持有当年度收益最高的标的，全年持有、无成本、无杠杆：

| 年份 | 当年最强标的收益 |
| --- | ---: |
| 2020（8–12月） | +24.5% |
| 2021 | +55.1% |
| 2022 | +64.6% |
| 2023 | +51.8% |
| 2024 | +34.3% |
| 2025 | +156.4% |
| 2026（至7月） | +71.9% |

**完美年度轮动复合 CAGR = 75.2%（8 标的）/ 75.3%（13 标的）。**

腾讯全历史 8 标的、2020-06-19 → 2026-10-30 的同一上限为 **75.8% CAGR**。

结论：**只靠“年度/低频选对一只资产”，这个池子的数学上限都不到 100%。** 100% 必须来自年内 timing、更高频轮动、新资产类别或杠杆；前两者是新的 alpha，不是 V5 调参。

## 诊断结论

1. **V5 的底层趋势/集中轮动逻辑是有效的**：1x 全历史 CAGR 约 67–71%，MDD -32.5%，成本 2x/3x 仍为正；不是“假策略”。
2. **但收益高度集中**：2025–2026 贡献大部分对数收益；最大单笔白银 LOF 约 +119%，去掉后 CAGR 从约 67% 降到约 55%。
3. **无杠杆 100% 不是参数问题**：完美年度轮动上限只有 75% 左右；扩展池也几乎不提高这个上限。
4. **V5 的 peak reset 是风险状态机修复，不是新 alpha**：它把 V4 的 269 次熔断降到 1 次，避免旧高水位反复砍仓；并没有增加新的收益来源。
5. **要无杠杆 100%，必须新增“年内 timing / 横截面 / 新资产类别”的 alpha**，这是策略重构，不是把 10/20 日动量改成 8/18 日。

## 建议

- **保留 V5 生产**：把它定位为 60–75% CAGR、-30% 到 -40% MDD 的趋势策略，不把 100% 当成迭代 KPI。
- **如果坚持无杠杆 100%**：启动新 alpha 研究，而不是 V5 调参。候选方向：
  1. 周频/日频横截面动量 + 波动率缩放；
  2. 趋势突破 + 回撤恢复（不是简单均线参数）；
  3. carry/基差/溢价（LOF 溢价、国债利差）；
  4. 更多低相关资产（跨境、商品、债券），但必须做容量/溢价/数据质量审核。
- **准入门槛**：任何候选必须先跑 2x/3x 成本、分年、滚动、去掉 top 交易、block bootstrap；再从 2026-11-02 起 252 个交易日真样本外；不加杠杆。
- **不要做的事**：在全历史上继续扫参数、用 2025 的白银行情反推规则、把完美年度上限当成可实现收益。

## 边界

- 扩展池回测用本地新浪缓存，区间止于 2026-07-27；与服务器腾讯 2026-10-30 不完全同期。
- 完美年度轮动是**上帝视角上界**，不是策略，不可交易。
- 2023–2024 已包含在历史回放中，不再是未触碰样本；真零样本从 2026-11-02 起算。
- 未计 LOF 溢价、停牌、容量、真实 14:50 成交；这些只会让结果更保守。
