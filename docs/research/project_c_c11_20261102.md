# C11：按 600322 精确模板复刻

- 日期：2026-11-02
- 目的：不再做宽泛“类似形态”，把 600322（2022-11-09）拆成硬条件，逐条复刻
- 数据：192 只当前上市 A 股（含 600322）；日线 qfq；幸存者偏差存在
- 研究 only，不接券商、不下单

## 600322 的精确条件

2022-11-07 是模板首次触发（11-09 也满足）：

| 条件 | 600322 2022-11-07 |
| --- | --- |
| 总市值 | 22.5 亿（<30 亿） |
| 价格 | 2.04（<3 元） |
| 距 60 日高 | -23.0%（-20% ~ -30%） |
| 5 日新高 | 收盘 2.04 > 前 5 日高 2.02 |
| 均线 | MA5 1.988 > MA10 1.996？11/07 实际 MA5 2.002 > MA10 1.991；收盘 > MA10 |
| 位置 | 收盘 < MA20，仍在 MA20 下方 |
| 量能 | 0.46x（0.35–0.8x） |
| MACD 柱 | hist -0.0245 > 前值 -0.0345，改善 |
| 卖出 | MACD 死叉（12/08），12/09 卖 2.52 |

## C11 规则

- 总市值 <30 亿
- 价格 <3 元
- 距 60 日高 -20% ~ -30%
- 收盘 > 前 5 日最高
- 收盘 > MA10，MA5 > MA10
- 收盘 < MA20
- 量/20 日均量 0.35–0.80
- MACD 柱较前一日改善
- 买入：T 收盘
- 卖出：MACD 死叉 / MA 死叉 / -7% 止损 / 最长 30 日
- 最多 4 只；按候选数均分现金（不再固定只投 25%）

## 关键发现

1. **精确模板能控制回撤**：MACD 版 MDD -10.3%，基本贴着 -10% 目标；MA 版 -9.4%。
2. **600322 就在这 2 笔里**：模板抓到了它；单笔约 +23%（11/07 2.04 → 12/09 2.52）。
3. **但 6.8 年只有 2 次信号**：模板太稀有，无法形成每月 12–30% 的复利。
4. **宽泛版为什么亏**：把大量“像 600322 但不是”的失败样本也买进去；精确版只做极少数高确定性案例。
5. **用户的 15%/月来自“找到并重仓这种稀有案例”**，不是每天都有信号；系统化的瓶颈是**候选频率/选择**，不是卖出规则。

## 这说明什么

- 你的方法不是“箱体公式”，是**极严格的事件筛选**：
  - 低价、小市值、深回撤、5 日新高、MA5>MA10、仍在 MA20 下方、低量、MACD 柱改善。
- 这个模板的回撤可控（-9.4% / -10.3%），但**太稀有**；要靠它月月 15%，必须每月找到 2–4 个同模板案例。
- 我们的 192 只样本太小；全 A 股/更多年份可能找到更多，但需要行业/板块/筹码数据来提高候选质量。

## 下一步

- 扩大股票池（全 A 股，不只 192 只），统计该模板每年出现次数；
- 加行业/板块（2022-11 地产链）和 market regime，看能否提高信号密度而不降低胜率；
- 不宽泛化阈值；宁可少做，不做“像但不是”的样本；
- 如果全 A 股一年也只有个位数信号，那 15%/月不可持续，只能作为机会型交易。
