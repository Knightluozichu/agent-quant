# Project C5：小盘横盘低吸、次日卖出（系统化尝试）

- 日期：2026-11-02
- 状态：研究 only，不接券商、不下单
- 用户经验：以前做横盘震荡的小盘股，低买、次日卖，能做到每月约 15%
- 目标：1 万本金、仅 A 股/ETF、不加杠杆、月 12–30%、最大回撤 -10%

## 先说明

这套策略和 C3 的“涨停追买”完全相反：它赚的是**横盘区间内的低吸反弹**，不是涨停延续。我用两套可复现的日线规则去翻译它，结果都没有复现 15%/月；但这不等于用户以前的方法无效，只说明**我的规则翻译没有抓住用户的真实 edge**。

## C5 基准版

### 规则
- 样本：当前上市 A 股随机 200 只（191 只有效），日线 qfq
- 小盘：每日按收盘市值（close × outstanding_share）横截面排名，取后 50%
- 横盘：20 日振幅 ≤15%，|20 日收益| ≤8%
- 低吸：3 日跌幅 ≤ -3%，收盘 ≤ MA20，收盘 ≥ 20 日最低 ×1.01
- 执行：T 收盘买入（14:50 生产代理），T+1 收盘卖出
- 仓位：最多 5 只等权；买入 0.15%、卖出 0.20%
- 风控：组合回撤 ≤ -10% 清仓

## C5 恢复版

### 规则调整
- 小盘：后 30%
- 低吸：3 日跌幅 ≤ -2%，收盘 ≤ MA20，收盘 ≥ 20 日最低 ×1.01
- 加确认：收盘 > 开盘（日内收回），且收盘 > MA60（不是下跌趋势）

## 为什么系统化版本失败

1. **“低点”不是收盘价**：用户说的低买，很可能是盘中下探/分时低点；日线收盘买入会买在下跌延续里。
2. **“横盘”是视觉/结构判断**：20 日振幅 + MA 只是粗代理，可能把下跌中继当成横盘。
3. **T+1 卖出太慢**：真实做的是次日冲高卖，系统版统一收盘卖，利润回吐。
4. **高换手成本**：1,700+ 次交易，双边 0.35% 成本会吃掉小反弹。
5. **样本/幸存者偏差**：当前上市样本虽偏差向上，但规则不对仍然亏。
6. **15%/月可能是特定年份/特定手法/少量样本**：需要交易记录验证，不能直接外推。

## 要复现用户的方法，需要这些信息

1. **小盘定义**：市值区间？流通市值还是总市值？是否排除 ST/次新？
2. **横盘定义**：看几天？振幅、均线、箱体上下沿怎么画？
3. **低买触发**：盘中跌到箱体下沿？分时新低？跌幅阈值？还是尾盘？
4. **卖出规则**：次日开盘、冲高、固定止盈、跌破均线？有没有止损？
5. **仓位**：一次几只？单只多少比例？是否满仓？
6. **真实记录**：最好给出过去一段时间的逐笔成交（日期/代码/买价/卖价/数量）；有记录才能复现 edge，而不是继续猜规则。
7. **样本区间**：15%/月持续了多久？最大回撤多少？最差月份？

## 结论

- 两套日线系统化版本都没有复现 15%/月，且回撤远超 -10%。
- 这不证明用户以前的方法不存在，而是证明**“横盘小盘低吸次日卖”不能被这几个日线阈值简单替代**。
- 在没有用户的精确规则/成交记录之前，继续调这些阈值就是过拟合。
