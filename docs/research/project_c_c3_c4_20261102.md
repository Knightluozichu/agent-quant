# Project C：C3 个股涨停延续 + C4 盘中 T+0（首轮回测）

- 日期：2026-11-02
- 状态：研究 only，不接券商、不下单
- 目标（用户）：1 万本金、仅 A 股/ETF、不加杠杆、月 12–30%、最大回撤 -10%
- 说明：本报告不使用旧策略；C3/C4 都是新候选。

## C3：A 股个股涨停延续

### 设计
- 样本：当前上市 A 股中随机抽取 200 只（排除 ST、北交所），成功取到 191 只日线（新浪 qfq）。
- 信号：T 日收盘涨停（主板 ≥9.5%，创业板/科创板 ≥19.5%），收盘接近当日最高，成交量 ≥20 日均量 1.5 倍。
- 执行：T+1 开盘买入；一字涨停/开盘涨停不买；T+2 开盘卖出（T+1 不能当天卖）。
- 仓位：最多 2 只，等权；成本买入 0.15%、卖出 0.20%；组合回撤 ≤ -10% 时清仓并重置 peak。
- 区间：2020-01 → 2026-10-30。

### 结果

| 指标 | C3 |
| --- | ---: |
| 期末权益 | 628.15 元 |
| 总收益 | **-93.7%** |
| CAGR | -33.3% |
| Sharpe | -1.51 |
| 最大回撤 | **-94.0%** |
| 月 ≥12% | 3 / 81 |
| 月 ≥20% | 2 / 81 |
| 月 ≥30% | 0 / 81 |
| 月中位数 | -1.89% |
| 涨停事件 | 1,200 |
| 实际成交 | 309 |
| 回撤清仓次数 | 40 |

### 解释
- 当前上市样本天然有**幸存者偏差**，通常会让结果偏好；即使这样仍然 -93.7%，说明“涨停次日追买”在样本内没有稳定优势。
- 一字板买不到，能买到的往往是高开/分歧板；T+1 买入后 T+2 才能卖，承担隔夜风险。
- -10% 组合回撤闸门触发 40 次，仍被跳空/连续跌停击穿到 -94%。

## C4：5 分钟盘中 T+0 试点

### 设计
- 数据：新浪 5 分钟线，仅最近约 2 个月（2026-08-27 → 2026-11-02），**不是 6 年回测**。
- 标的：159915 创业板ETF、510300 沪深300ETF、000001 平安银行。
- 结构：50% 底仓 + 50% 现金；盘中用 5,000 元做 T+0 overlay。
- 信号：10:00 相对 09:35 开盘的首段涨跌 >0.2%。
  - momentum：首段涨→买、跌→卖底仓再买回；
  - fade：反向。
- 14:55 平掉 overlay；成本单边 0.15%。

### 结果（总收益 / 最大回撤 / overlay PnL）

| 标的 | 规则 | 总收益 | 最大回撤 | overlay PnL |
| --- | --- | ---: | ---: | ---: |
| 159915 | momentum | -23.53% | -23.53% | -865 元 |
| 159915 | fade | -16.42% | -17.52% | -155 元 |
| 510300 | momentum | -14.33% | -14.33% | -810 元 |
| 510300 | fade | -5.63% | -6.37% | +60 元 |
| 000001 | momentum | -2.23% | -5.80% | -339 元 |
| 000001 | fade | -5.94% | -8.02% | -711 元 |

### 解释
- 2 个月、41 个交易日，样本太短，不能证明长期无效；但也**没有任何一个月接近 12–30%**。
- 6 个组合里 5 个亏损；唯一 overlay 正收益的 510300 fade 只有 +60 元（5,000 元 overlay 约 +1.2%/2个月），扣掉底仓后总收益仍 -5.63%。
- 5 分钟数据只有约 2 个月，**无法做 6 年回测**；要验证 C4，必须买/接分钟级历史数据，并模拟真实盘口/排队/滑点。

## 合并结论

1. **C3 不通过**：即使有幸存者偏差，仍 -93.7%、MDD -94%；涨停次日追买不是稳定 alpha。
2. **C4 试点不通过**：2 个月内没有接近目标，且数据长度不足以做长期结论。
3. **-10% 回撤在日线/5分钟试点下仍被击穿**：C3 的 40 次清仓没有阻止 -94%；跳空、连续跌停、T+1 是结构性的。
4. **月 12–30% + MDD -10%** 在 C3/C4 也没有出现可行证据；不做参数救援。

## 下一步

- 如果继续 C：需要**付费/自建分钟级历史数据**（至少 3–5 年）、逐笔/盘口、真实排队与滑点；C4 才能从“2 个月试点”变成可回测策略。
- 如果 -10% 是硬约束：目标应降到月 1–2%；当前所有候选都不支持 12–30%。
- 如果月 12–30% 是硬目标：MDD 必须放宽到 -30% 到 -50%，且仍不承诺。
