# Project C6：总市值 <100 亿、箱体低点买、剪刀差卖、止损、2–4 只

- 日期：2026-11-02
- 状态：研究 only，不接券商、不下单
- 用户规则：总市值 <100 亿；横盘箱体低点买；剪刀差卖；要止损；稳定 2–4 只
- 目标：1 万本金、仅 A 股/ETF、不加杠杆、月 12–30%、最大回撤 -10%

## 规则落地

- 样本：当前上市 A 股随机 200 只（191 只有效），日线 qfq
- 市值：`close × outstanding_share < 100 亿`，逐日判断
- 横盘：60 日箱体振幅 ≤25%，|60 日收益| ≤10%
- 低点：收盘位于箱体底部 8% 区间，且不低于 60 日最低
- 买入：T 收盘买（14:50 代理）
- 卖出：
  - MA 版：MA5 下穿 MA10（死叉），次日开盘卖；
  - MACD 版：DIF 下穿 DEA（死叉），次日开盘卖；
  - 止损：收盘跌破买入价 -5%，次日开盘卖；
  - 最长持有 10 个交易日。
- 仓位：最多 4 只等权；买入 0.15%、卖出 0.20%
- 组合回撤 ≤ -10% 清仓

## “能找到多少只”

- 样本 191 只中，7 年多里实际交易过 **99–100 只**；
- 仓位上限 4 只，按规则稳定保持 2–4 只；
- 但“能交易很多只”不等于“能赚钱”：两版都亏，回撤 -48% 到 -51%。

## 为什么还是不行

1. **低点用收盘价，不是盘中低点**：用户说的“横盘低点”很可能是分时下探/箱体下沿的盘中价格；日线收盘买会买在下跌延续或反弹末端。
2. **剪刀差定义未唯一**：MA5/MA10 和 MACD 都试了，都亏；如果用户指的是价格与均线的剪刀差、KDJ 死叉或均线发散，需要明确。
3. **T+1 卖出**：死叉确认在收盘，次日开盘卖；真实操作可能是盘中冲高卖，收益差异大。
4. **止损 -5%**：日线止损在 T+1 开盘执行，跳空会击穿；两版最大回撤仍 -48% 到 -51%。
5. **高换手成本**：300+ 次交易，双边 0.35%，吃掉小箱体利润。
6. **样本/幸存者偏差**：当前上市样本偏差向上，仍亏；说明规则没有抓到用户的实际 edge。

## 需要用户补充

1. **“剪刀差”到底是哪一个**：MA5/MA10 死叉、MACD 死叉、价格与均线剪刀差，还是别的？
2. **低点怎么确认**：盘中跌到箱体下沿就买，还是等分时收回/尾盘买？
3. **止损阈值**：-5%？-7%？还是跌破箱体下沿？
4. **最长持有**：只做次日，还是死叉前一直拿？
5. **真实成交记录**：给 20–50 笔（日期/代码/买价/卖价/数量），我能反推你的真实 entry/exit，而不是继续猜。
6. **样本区间**：15%/月持续了多久？最大回撤多少？最差月份？

## 结论

- 按目前能落地的日线规则，C6 两版都失败：-29.4% / -43.8%，MDD -51.3% / -48.3%，没有一个月 ≥20%。
- 这不是说用户的方法不存在，而是说**“<100 亿 + 箱体低点 + 剪刀差 + 止损 + 2–4 只”还不足以系统化复现**。
- 下一步必须拿真实成交记录或更精确的盘中规则；否则继续调阈值就是过拟合。
