# “4500%”是哪来的：严格 V3.5 研究结果拆解

- 日期：2026-11-02
- 来源：`data/v9_results/strict_v35_audit.json`
- 结论：**4500% 是严格 V3.5 的 1x 成本、same-close 14:50 代理结果；不是可直接部署的实盘收益。**

## 1. 数字对上了

严格 V3.5（strict V3 base + frozen V4 overlay）：

| 指标 | 1x 成本 |
| --- | ---: |
| 区间 | 2020-06-19 → 2026-08-11 |
| 初始 | 100,000 元 |
| 期末 | **4,852,093.98 元** |
| 总收益 | **+4752.09%** |
| CAGR | 88.1% |
| 最大回撤 | -28.6% |
| Sharpe | 2.52 |
| 成交腿 | 221 |

你记得的“4500%”就是它：**+4752%**，不是 4500 整。

## 2. 为什么不能直接拿去和 V5 比

### 2.1 执行口径：same-close 代理

`execution_model_warning` 原文：

> historical official close is a same-price 14:50 execution proxy; historical intraday snapshots are unavailable

意思是：**用历史收盘价当 14:50 成交价**，不是次日开盘，也没有盘中快照。
这是一个**乐观上界**，不是严格可执行回测。

### 2.2 没有真实 OOS

- `live_oos_observations: 0`
- `historical_oos_label_valid: false`
- 原因：严格 V3.5 是在看完完整历史和 V4/V3-G 审计之后才提出的，历史区间不能算未触碰样本外。

### 2.3 高过拟合风险

`assessment`：

- `classification: high_overfit_risk`
- `research_status: research_candidate_only`
- `statistical_increment_pass: false`
- `temporal_concentration_warning: true`
- `cost_stress_pass: false`
- 建议：**do not replace production from this retrospective result**

候选选择涉及 17 个以上 V4 参数变体，存在选择偏差。

### 2.4 成本压力：3x 直接崩塌

| 成本 | 期末 | 总收益 | CAGR | MDD |
| ---: | ---: | ---: | ---: | ---: |
| 0x | 6,705,182 | +6605% | 98.3% | -27.1% |
| **1x** | **4,852,094** | **+4752%** | **88.1%** | **-28.6%** |
| 2x | 3,393,765 | +3294% | 77.5% | -30.8% |
| **3x** | **14,646** | **-85.4%** | -26.9% | **-94.5%** |

3x 成本下不是“少赚”，是**路径依赖崩塌**：成本改变回撤 → 改变风险动作 → 改变后续交易，最后 -85%。

## 3. 和 V5 的正确对比

| 策略 | 执行 | 1x 总收益 | 3x 成本 | 真 OOS |
| --- | --- | ---: | ---: | --- |
| 严格 V3.5 | same-close 14:50 代理 | +4752% | **-85.4%** | 无 |
| V5 | next-open | +2506% | **+1211%** | 未完成 252 日 |

- 账面上，严格 V3.5 1x 比 V5 高；
- 但它不是同一执行口径，也没有真 OOS，3x 成本直接崩；
- **V5 的 3x 成本仍为正，稳健性明显更好。**

## 4. 结论

- “4500%”真实存在：严格 V3.5 的 1x same-close 研究结果 **+4752%**；
- 但它不能算“比 V5 更好”：
  - 执行口径乐观；
  - 无真 OOS；
  - 高过拟合风险；
  - 3x 成本 -85%；
- 它是**研究候选**，不是生产策略；不能拿这个数字做收益承诺。

## 5. 如果要对齐口径

下一步可以：

1. 用 next-open 重跑严格 V3.5；
2. 用和 V5 相同的 Tencent/Sina 输入；
3. 2x/3x 成本；
4. 252 日真样本外；
5. 再和 V5 比。

在这些完成前，**不要把 +4752% 和 V5 的 +2506% 直接排名**。
