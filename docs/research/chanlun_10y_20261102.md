# 简化缠论 10 年 A 股回测（1 万本金）

- 日期：2026-11-02
- 标的：286 只当前上市 A 股（随机 300 只样本，有效 286 只）
- 区间：2015-01 → 2026-10（约 11.8 年）
- 本金：10,000 元；不加杠杆；最多 4 只；T+1 次日开盘；成本买入 0.15%、卖出 0.20%
- 规则：简化缠论“三买”
  - 分型/笔/中枢按简化口径；
  - 价格突破最近中枢 ZG，回踩不破 ZG，买入；
  - 收盘跌破中枢 ZD、-7% 止损、或最长 30 日卖出。
- 声明：这是**简化可回测版**，不是原书唯一口径；结果不能代表所有缠论用法。

## 结果

| 指标 | 数值 |
| --- | ---: |
| 期末权益 | **8,501.65 元** |
| 总收益 | **-15.0%** |
| CAGR | -1.4% |
| 最大回撤 | **-86.2%** |
| 夏普 | 0.28 |
| 交易次数 | 1,288 |
| 组合止损次数 | 70 |
| 月 ≥10% | 20 / 141 |
| 月 ≥20% | 7 / 141 |
| 最好月 | +80.5% |
| 最差月 | -41.2% |

## 解读

- 10,000 元跑 11.8 年，最后 **8,501 元**，没有跑赢本金。
- 中间有 20 个月 ≥10%、7 个月 ≥20%，但最大回撤 -86.2%，属于“高波动、不可复利”。
- 1,288 次交易、70 次组合止损，交易成本和假突破把收益磨掉。
- 简化三买在 2015–2026 的 A 股样本里**没有稳定正收益**。

## 为什么

1. **缠论的三买依赖中枢口径**，不同人画的中枢不同；程序化后大量假突破。
2. **T+1 + 次日开盘**：回踩确认后买入，常买在反弹末端。
3. **止损 -7% 与中枢 ZD 双重退出**，在震荡市频繁被打。
4. **样本/幸存者偏差**：当前上市样本偏差向上，仍然亏损，说明不是样本问题。
5. **4 只分散 + 组合 -10% 清仓**，在极端行情下仍被跳空击穿到 -86%。

## 结论

- **简化缠论三买 10 年回测：10,000 → 8,501 元，-15%，MDD -86.2%。**
- 它不是月 10% 策略，也不是稳定复利策略。
- 这不证明“缠论无效”，只证明**这一套可执行简化规则无效**；缠论的其他买卖点/主观画法需要另外明确规则再测。
- 如果继续，应该分别实现一买/二买/三买/背驰，做统一样本外比较，而不是拿一个版本代表全部缠论。
