# C10：横盘结束换股（箱体破位轮动）回测

## 先解释 -99.5%

- -99.5% 来自 **C9 的“1 只满仓”压力测试**，不是用户的 2–4 只轮动。
- 单票全仓 + 反复止损/跳空 + 84 次交易复利，会把小概率连续亏损放大到接近归零。
- 用户实际是 2–4 只轮动；C9 的 4 只版本是：总收益 +22.1%，最大回撤 -33.7%，不是 -99.5%。

## C10：箱体破位就换股

规则在 C9 基础上增加：

- 入场时记录箱体下沿（60 日最低）；
- 收盘跌破入场箱体下沿 → 次日开盘卖出，换下一个横盘候选；
- 仍保留 MACD/MA 死叉、-7% 止损、最长 30 日；
- 最多 4 只。

## 结果

| 指标 | C10 |
| --- | ---: |
| 总收益 | **-32.6%** |
| CAGR | -5.6% |
| 最大回撤 | **-46.4%** |
| 月 ≥12% | 0 / 81 |
| 月 ≥20% | 0 / 81 |
| 月 ≥30% | 0 / 81 |
| 交易次数 | **854** |
| 交易过的股票 | 64 |

## 分析

- “箱体破位就换”在日线上会大量**假破位**：刚跌破下沿就卖，卖在低点；随后股票拉回，又错过。
- 854 次交易、双边 0.35% 成本，直接把收益磨没。
- 用户手动能过滤“真破位/假破位”（看盘口、板块、量能），机械版做不到。
- 结果比 C9 4 只版本更差：C9 +22.1%/-33.7%，C10 -32.6%/-46.4%。

## 结论

- -99.5% 是单票满仓压力测试，不是用户方法；用户 2–4 只的实际对应是 C9 4 只：+22.1%/-33.7%。
- “横盘结束换股”这个原则对，但**机械地一破位就换会 whipsaw + 成本爆炸**；C10 反而更差。
- 要复现用户，需要“真破位/假破位”的判断条件，而不是简单 `close < 箱体低点`。
- 下一步：给破位加确认（收盘跌破 + 次日不收回 / 放量 / 板块同步走弱），并控制换手；但仍不能保证 12–30%/月 + -10%。
