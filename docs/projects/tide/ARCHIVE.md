- 英文名：**Project Tide**
- 立项日期：2026-11-02
- 状态：**存档 / 研究 only / 不接券商 / 不下单 / 不部署**
- 核心隐喻：机会像潮汐，成簇出现；有潮汐才做，没潮汐就空仓。

## 1. 立项目标

- 起始资金：10,000 元
- 范围：仅 A 股股票 / ETF
- 杠杆：不加
- 目标：月 12–30%（后期用户要求至少月 10%），最大回撤 -10%，可复利
- 现实结论：**月月 10%+ / 回撤 -10% / 无杠杆，样本不支持，判定 no-go**
- 保留价值：**机会型增强**，不是月度机器

## 3. 最关键的发现

### 600322 模板（2022-11-09）

- 总市值 <30 亿、价格 <3 元；
- 距 60 日高 -20% ~ -30%；
- 收盘 > 前 5 日最高；
- 收盘 > MA10，MA5 > MA10；
- 收盘 < MA20；
- 量/20 日均量 0.35–0.80；
- MACD 柱较前一日改善；
- 买入 T 收盘；
- 卖出 MACD 死叉 / -7% 止损 / 最长 30 日。

600322：2022-11-07 2.04 → 12/08 MACD 死叉、12/09 2.52，约 **+23%**；用户记得的 11/09 买点 +19.4%。

### 频率与月度

- 1,141 只低价/随机样本：33 个信号 / 6.8 年，胜率 51.5%、均值 +2.13%、中位 +1.74%；
- 随机 489 只（排除 600322）：仅 2 个信号 / 6.8 年，推算全 A 约 3 个/年；
- 6.8 年只有 3 个活跃月份有 ≥2 只独立股票；
- C11 组合 81 个月仅 1 个月 ≥10%，0 个月 ≥20%；
- **月月 10% 没有样本支持。**

### 行业

- 行业强度过滤无效：正动量组胜率 36.4%，负动量组 59.1%；
- 600322 是弱势地产板块的政策反转，不是行业强度；
- 同行业 ≥2 只的多股票簇胜率 28.6%，不是“板块共振”。

## 4. 最终决策

- **改成机会型增强**：只做 600322 精确模板；有信号才做，没有就空仓；最多 2–4 只；不设月度收益 KPI。
- **月月 10%+ / MDD -10% / 无杠杆：no-go。**
- **不再扫参数、不再宽泛化阈值、不再用行业强度/簇硬凑。**
- 不接券商、不下单、不部署；本项目仅存档。

## 5. 如果未来重开

1. 全 A 股历史时点低价池（消除当前低价选择偏差）；
2. 一买/二买/背驰分别实现，统一样本外；
3. 行业反转/政策事件数据；
4. 若仍只有个位数信号/年，保持机会型，不追月度目标；
5. 若要月月 10%，必须放宽回撤或加杠杆/衍生品，二选一。

## 7. 复盘四步

1. **目标**：1 万、A 股、无杠杆、月 12–30%、MDD -10%。
2. **结果**：找到 600322 精确模板（真实、稀有、+23% 单笔），但无法月月复利；月月 10 no-go；缠论三买负收益。
3. **原因**：信号频率不足；模板依赖板块/政策/主观选择；日线/T+1 无法保证 -10%；放宽阈值会引入大量失败样本。
4. **沉淀**：有明确规则的事件型策略可以做机会增强；不要用月度收益 KPI 逼策略交易；不要用行业强度/簇数量替代真实催化。
