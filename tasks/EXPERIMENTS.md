## 2026-08-11: V3-G 全池快慢动量研究归档

## 2026-08-12: V4 新仓失败保护叠加研究

- **状态**: 完成；研究/影子候选，未批准生产
- **问题**: V4 的 10/20 日慢动量与 2/2 确认可能在新仓快速反转时滞后，造成
  “历史排名仍强、账户持仓已大亏”的路径风险。
- **方法**: 仅检查买入后前 3 个交易日，沿用既有预注册冲击阈值：单日收益
  `<=-5%` 或入场累计收益 `<=-10%`。不做参数网格，比较直接退防御、首个完整
  V4 候选优先、正趋势相对替代、选择性否决四种机制；复用生产 V4 因子、V3-G
  过滤、14:50 当日成交近似、费用与风险路径。
- **数据**: 2020-06-19 至 2026-08-11，1,485 个观测日，112 次入场。
- **复现**: `uv run python scripts/exp_v4_entry_guard.py --save`
- **结果文件**: `data/v9_results/v4_entry_guard_research.json`

### 核心结果

| 方案 | 期末 | Sharpe | MDD | 新仓保护触发 |
|---|---:|---:|---:|---:|
| V4 基线 | 5,258,018 | 2.559 | -28.62% | 0 |
| 冲击后退防御 | 4,932,969 | 2.556 | -28.67% | 2 |
| 首个V4候选否则防御 | 4,932,969 | 2.556 | -28.67% | 2 |
| 正趋势替代否则防御 | 4,932,969 | 2.556 | -28.67% | 2 |
| 选择性新仓否决 | 5,258,018 | 2.559 | -28.62% | 0 |

- 无条件新仓止损的 2 次历史触发都没有合格替代品，退出未改善最大回撤，期末值
  下降约 6.2%，否决上线。
- 选择性规则固定为：单日 `<=-5%` 时，仅当最强合格替代品慢动量和趋势为正，
  且 3 日、5 日收益均超过持仓时才切换；否则继续持有。若前三日入场累计
  `<=-10%`，无条件退防御至下一固定网格。
- 默认选择性规则在历史上 0 次触发，IS/OOS 与 0x/1x/2x 成本路径均与 V4 一致；
  说明没有历史回归，但也说明缺乏真实事件证据。`-4%` 敏感性仅靠 2026-08-03
  单一事件改善结果，视为过拟合信号，不采纳。
- 历史新仓路径中，第 1/2/3 日最差入场收益分别为 -5.85%/-7.12%/-3.21%，
  没有 `<=-10%` 样本，因此灾难阈值只能作为压力安全网，不能声称已被回测验证。
- 用户压力路径（持仓 -5%/-8%/-3%，替代品 +1%/+2%/+3%）中，若首日有合格
  替代品，选择性规则首日切换，三日毛收益由 -15.22% 改为约 -0.19%；若无合格
  替代品，第二日累计 -12.6% 时退防御，避免第三日继续下跌。该结果是确定性机制
  压力测试，不是历史收益证据。

### 结论

- 当前最合适的候选是 `entry_guard_selective`，但证据等级仅为“机制合理、历史零
  触发”。先作为 14:50 **影子告警/人工风险否决建议**，不自动改目标、不连接券商。
- 生产 V4、2/2 正常轮动、3 交易日锁和人工成交边界均未修改。若未来考虑激活，
  必须单独获得用户授权，并补充真实触发样本或预先接受“灾难保险规则不以收益改善
  为晋升条件”的风险治理决策。

## 2026-08-12: V4 两阶段入场研究

- **状态**: 完成；全量两阶段入场不晋级，未修改生产 V4
- **假设**: 新仓先投入正常目标仓位的 50% 或 60%，观察满 2 个交易日后再补满，
  能降低“高慢动量资产刚买入即反转”的账户损失。
- **方法**: 新风险资产首仓使用 50%/60% 暴露；从持仓年龄第 2 日开始，仅当该资产
  仍是当日日频 V3-G 目标、仍 eligible、慢动量为正、短趋势为正且新仓保护未触发
  时补至正常仓位。比较纯分段及叠加 `entry_guard_selective` 的四个预注册版本，不做
  参数扫描；复用 canonical V4 的排名、过滤、风控、费用和 14:50 当日成交近似。
- **数据**: 2020-06-19 至 2026-08-11，共 1,485 个观测日。
- **复现**: `uv run python scripts/exp_v4_staged_entry.py --save`
- **结果文件**: `data/v9_results/v4_staged_entry_research.json`

### 1x 全周期结果

| 方案 | 期末 | CAGR | Sharpe | MDD | 分段首仓/补仓 | 保护触发 |
|---|---:|---:|---:|---:|---:|---:|
| V4 基线 | 5,258,018 | 90.59% | 2.559 | -28.62% | 0/0 | 0 |
| 50% 首仓 | 3,298,124 | 76.65% | 2.361 | -23.23% | 110/95 | 0 |
| 60% 首仓 | 3,622,812 | 79.37% | 2.412 | -24.36% | 110/95 | 0 |
| 50% 首仓 + 选择性保护 | 3,298,124 | 76.65% | 2.361 | -23.23% | 110/95 | 0 |
| 60% 首仓 + 选择性保护 | 3,622,812 | 79.37% | 2.412 | -24.36% | 110/95 | 0 |

- 50% 首仓把全周期 MDD 改善 5.38pp，但期末值下降 37.27%，Sharpe 下降 0.198；
  60% 首仓把 MDD 改善 4.26pp，但期末值下降 31.10%，Sharpe 下降 0.146。
- 风险改善主要位于 IS：IS MDD 从 -28.62% 改为 -23.23%/-24.36%；OOS MDD
  仅从 -18.96% 改为约 -18.88%，但 OOS 指数化期末从 1,548,076 降至
  1,105,743/1,183,276。说明全量延迟风险暴露削掉了大量有效趋势初段。
- 110 次分段首仓中仅 95 次补满；其余在确认前已换仓或未再次满足补仓条件。
  叠加选择性新仓保护的路径完全相同，因为历史保护条件仍为 0 次触发。
- 0x/1x/2x 成本下，50%/60% 版本的期末与 Sharpe 均低于 V4；3x 下 canonical
  V4 与研究基线逐日完全一致地发生既有非线性风控路径崩溃，不能把分段版本的相对
  存活解释为稳健收益证据。

### 用户压力路径

在白银依次 -5%/-8%/-3%、黄金 +1%/+2%/+3% 的确定性毛收益路径中：

| 机制 | 50% 首仓 | 60% 首仓 | V4 满仓持有 |
|---|---:|---:|---:|
| 无替代、继续持有白银 | -7.61% | -9.13% | -15.22% |
| 首日有合格黄金并切换 | -0.03% | -0.06% | — |
| 无合格替代、第二日累计破 -10% 后退现金 | -6.30% | -7.56% | — |

以上仅证明仓位缩放会按比例截断特定灾难路径，不是历史绩效证据，且未计入整数手数
与交易成本。

### 结论

- **否决把 50%/60% 两阶段入场全量叠加到当前 V4**：它降低绝对回撤，但长期收益、
  IS/OOS Sharpe 和趋势捕获都变差，风险调整后没有占优。
- 如果用户的硬约束是“新仓极端路径最多先损失满仓的一半”，50% 版本可作为独立的
  保守风险档位继续影子观察，但它不是 V4 的免费增强，也不应自动替换当前生产参数。
- 后续如继续研究，应预注册一个**只在可观测追高脆弱状态下启动**的条件式分段规则，
  而不是扫描首仓比例或把所有 110 次新仓一律降仓；该研究需另立实验，避免事后拟合。

## 2026-08-12: V4 六年半过拟合数学审计

- **状态**: 完成；判定为高过拟合风险，但现有证据不足以证明 V4 无效
- **审计对象**: 只审计 V4 相对 canonical V3-G 的增量，不用 V4 自身很高的绝对
  Sharpe 代替增量证据。
- **数据**: 2020-06-19 至 2026-08-11，共 1,485 个交易日；V4 上线日为
  2026-08-11，因此真正 post-launch OOS 为 0。
- **方法**: 至少 17 个历史非基线候选的 White Reality Check；8 个连续时间块的
  CSCV/PBO；V4 三个差值阈值分别按 80%/100%/120% 组成 27 点局部邻域；Newey-West
  HAC；5/20/60 日移动块自助法 5,000 次；逐年、252 日滚动和 39 次提前轮动归因。
- **复现**: `uv run python scripts/exp_v4_overfit_audit.py --bootstrap-samples 5000 --save`
- **结果文件**: `data/v9_results/v4_overfit_audit.json`

### 结论拆分

**不存在明显的局部阈值尖峰：**

- 27/27 个 ±20% 阈值邻域均跑赢 V3-G，增量期末范围 +7.67% 至 +35.41%，中位数
  +26.53%；当前 V4 中心参数按期末值排第 4/27，而非事后唯一最优点。
- CSCV/PBO 在全部记录候选中为 17.1%，在 consensus 家族中为 10.0%；这反对
  “一换时间块，训练最优立刻掉到样本外末位”的典型参数过拟合叙事。
- 两日确认是关键结构而非平滑参数：改成一日确认后期末降至 2,752,203，Sharpe
  1.967；持有锁 3 日改 2 日期末为 4,776,480，改 4 日与当前路径相同。

**但增量统计证据不足且高度集中于后期：**

- 当前数据下 V3-G 期末 3,958,584，V4 期末 5,258,018，相对财富 +32.83%；对应
  平均年化相对收益约 +4.94%，20 日块自助法 95% 区间为 **-3.03% 至 +14.54%**，
  跨过 0；Newey-West 单侧 p 值约 0.128。
- 对 17 个已记录非基线候选作多重试验校正，20 日块 White Reality Check
  `p=0.755`；只保留四个 consensus 候选仍为 `p=0.340`，均未达到 5% 显著性。
- 7 个自然年中 V4 相对 V3-G 赢 4 年；20 个步长 63 日的滚动 252 日窗口只赢
  11 个，最差窗口 -7.81%，最好 +24.26%。
- V4 总相对对数收益的 **99.1% 来自 2024 年以后**；2020-2023 合计仅约 +0.24%。
  2025、2026 分别相对 V3-G +16.44%、+14.14%，是主要增量来源。
- 39 次提前轮动的 5/10/20 日相对胜率为 51.3%/66.7%/69.2%，未校正单侧符号
  检验 p 值为 0.500/0.0266/0.0119；事件窗口有重叠且机制经过候选选择，不能把
  后两个 p 值直接当成独立、已校正的显著证据。

### 数学判定

- **不是典型“参数点调到尖峰”的过拟合；是较高的样本阶段/制度过拟合风险。**
  参数邻域和 PBO 提供了机制稳定性的正证据，但收益时间集中、置信区间跨零、多重
  试验不显著以及真正 OOS 为零，使当前 6.5 年回放不足以验证增量可持续。
- 现有结果不能逻辑推出“V4 必然无效”，也不能支持“Sharpe 2.56 已证明有效”。
  正确状态是 provisional：保持参数冻结，以 V3-G 为并行影子基准收集未来数据。
- 历史回放使用 T 日及以前数据，不存在数组越界式未来函数；但日线正式收盘价被当作
  14:50 同价成交近似，缺少历史盘中快照造成的执行偏差尚未量化。
- 本审计未修改生产 V4。建议至少积累 252 个完全未参与调参的交易日后复审；在此
  之前新增数据只允许一次性前推评估，不允许边看结果边改阈值。

2. 逻辑合取版：删除净值反馈；只有“相关集中+下行波动加速”同时成立才清仓，只有
   “弱广度+领涨不稳”同时成立才半仓。CAGR回升至73.47%，但MDD仍为-29.77%。
3. 稀疏尾部确认版：若发生单日-5%或三日-10%冲击且V4不换仓，T+1清仓；若V4
   当日换仓，则把冲击风险以70%仓位带入新标的；其余仅在20日波动>45%、5日动量
   衰减<-2个百分点、价格<MA10、动量分<8%四项同时成立时降到70%。四个阈值来自
   旧V3尾部研究先验，不用旧V3结果冒充V4验证。

### 全周期结果（2020-06-19至2026-08-11，1,485日）

| 方案 | CAGR | Sharpe | MDD | 平均暴露 | 结论 |
|---|---:|---:|---:|---:|---|
| 冻结V4 | 90.59% | 2.559 | -28.62% | 100.0% | 基线 |
| 绝对趋势 | 88.97% | 2.526 | -28.91% | 98.4% | 几乎不降MDD |
| 市场广度 | 70.00% | 2.236 | -23.22% | 81.2% | 降风险但收益代价大 |
| 系统压力 | 65.26% | 2.065 | -21.64% | 78.4% | MDD改善24.4%，仅保留72.0%CAGR |
| 领涨稳定性 | 83.02% | 2.361 | -27.69% | 96.6% | 改善不足 |
| 加法投票 | 47.18% | 1.553 | -33.50% | 63.6% | 明确失败 |
| 合取确认 | 73.47% | 2.156 | -29.77% | 90.3% | 明确失败 |
| 稀疏尾部确认 | 86.72% | 2.487 | -29.09% | 99.1% | 局部有效、全局失败 |

- 稀疏尾部确认保留95.73% CAGR，7个自然年在本样本均为正，2x成本期末
  3,064,249；但MDD改善为-1.66%，即略微恶化。9点单轴±20%邻域0/9通过联合约束。
- 2026-08-10/11同价代理下，V4两日复合-12.21%，稀疏尾部确认版-6.98%，损失
  减少42.82%。这证明它能阻断第一击后的第二击，不代表能预测或避免第一击。
- V4历史最大回撤发生在2022-03-09至05-24，共49个交易日；期间V4在原油、豆粕、
  纳指、黄金、创业板之间切换7次。它是相关性变化和轮动反复造成的慢性磨损，不是
  单个高动量标的连续暴跌，所以冲击断路器覆盖不了该峰谷。
- 20日块5,000次固定策略自助法中，满足“保留85%CAGR且MDD改善20%”的概率仅
  1.08%；CAGR保留95%区间84.26%-105.11%，MDD改善区间-14.49%-16.38%。
- **数学结论**: 当前数据没有找到同时满足高收益保留和显著压低MDD的信号组合。
  系统压力/波动预算能降低MDD，但历史代价是约29%-35%的CAGR；稀疏冲击信号能
  保护本周类型的连续暴跌，却不降低全局最大回撤。二者应作为不同风险产品讨论，
  不应继续追加阈值把同一历史拟合到联合目标。真正下一步是冻结影子前推，或由用户
  明确选择“高收益+事故断路器”与“较低收益+约20%回撤目标”之间的风险预算。
