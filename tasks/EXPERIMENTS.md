## 2026-08-10: V3-G 门控版暴跌过滤研究

**实验脚本**: 13 个 exp_*.py（详见 git log ecff478）
**结果JSON**: 12 个 data/v9_results/*.json
**核心结论**: 
- 门控放行期望为负（频率扫描单调恶化、置换88%分位、跨池归零）
- 但 thr=0.01 参数区在14次分歧下保持+10.0%，扰动全过，成本全过
- 置换92%分位（11/12随机比真实差），用户决策接受上线
- 关键教训：参数全网格必须覆盖全部7个可调参数，单参数扫描会误判方向

## 2026-08-11: V3-G 全池快慢动量研究归档

- **状态**: 完成；2026-08-11 经用户明确批准上线
- **假设**: 在 V3-G 的 5 日网格之外，只在全池出现持续且足够强的领导权交替时换仓，能减少持仓见顶后的利润回吐。
- **方法**: 复用服务器 V3-G 选股、门控及风控路径；关闭全部降仓层；14:50 当日成交近似；仅使用 T 日及以前数据；非网格换仓最短持有 3 日。
- **数据**: 100,000 元，2020-06-19 至 2026-08-10，共 1,484 个观测日；2020、2026 为非完整年度。
- **源结果**: `data/v9_results/v3g_full_pool_fast_slow.json`
- **正式档案**: `data/qixing_results/v3g_latest_research_20260811.json`
- **复现命令**: `uv run python scripts/exp_v3g_full_pool_fast_slow.py`

### 结论

- V4（V3-G + 全池严格快慢共振）是 1x 全周期表现最好的研究项，但 IS 终值与基线几乎相同，增益主要集中于 2024-2026，且最大回撤扩大约 6.1pp。
- 慢动量领先 1pp 的 1x 终值提高，但夏普低于基线；2x 成本下终值与基线几乎相同，风险更高。
- 两套覆盖层在 3x 成本下都会触发非线性的持仓/风控反馈并失效，因此不能按 1x 收益批准生产。
- 用户在了解回撤扩大和高成本压力失效风险后明确要求实施 V4。生产实现提炼到
  `scripts/qixing_v4.py`，研究回放与实盘共用同一因子和决策函数。
- 共源复验结果不漂移：V4 期末 `5,587,052.914359309`，V3-G 基线期末
  `4,206,294.955514772`；V4 轮动事件流 SHA256 为
  `388a9dba6b7b83d78609bbe7afc8cdafbc83c4cc3a2b7fd6c05bb6ac0fe33e73`。
