# ISSUES.md - 问题与阻塞记录

> 记录项目中发现的问题、阻塞和待解决事项

## 格式

```
### I-XXX: 问题标题
- **日期**: YYYY-MM-DD
- **优先级**: P0 (阻塞) | P1 (高) | P2 (中) | P3 (低)
- **状态**: 开放 | 处理中 | 已解决 | 已关闭
- **描述**: 问题详情
- **影响**: 影响哪些任务
- **解决方案**: 如何解决（解决后填写）
```
